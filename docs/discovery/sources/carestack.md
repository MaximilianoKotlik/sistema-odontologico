# CareStack

- **URL:** https://www.carestack.com/
- **Fecha de investigación:** 2026-11-16

## Problema que resuelve
Software dental cloud todo-en-uno para consultorios y DSO.

## Usuarios objetivo
Consultorios y grupos/DSO multisede.

## Features detectadas
- Agenda multisede y auto-reserva online (Reserve with Google)
- Recordatorios y notificaciones
- Charting general y periodontal
- Imaging integrado y producto IA Aeka
- Pagos: tarjeta en archivo, planes con débito automático, text-to-pay
- Claims y elegibilidad
- Sección Developers / API

## Posicionamiento
Plataforma única cloud para grupos.
