## Problema que resuelve

## Usuarios objetivo

## Features detectadas
- Agenda: Vista por día o semana, filtros por profesional (sitio oficial). Sillones/boxes, sobreturnos, bloqueos, duración variable: No evidenciado.
- Turnos: Link público de reserva online; WhatsApp con confirmaciones, avisos de cambios y recordatorio D-1 vía Meta Cloud API (afirmación comercial). Lista de espera, chatbot: No evidenciado.
- Clínica: Odontograma fechado con histórico y comparación de versiones, periodontograma, notas clínicas por paciente. Presupuestos/imágenes: No evidenciado.
- Administración: Imputación de pagos FIFO sobre deuda, saldo a favor, multi-moneda, reportes. Mercado Pago: mencionado, se configura tras el trial. Facturación electrónica DGI: No evidenciado. Obras sociales/mutualistas: No evidenciado.
