# Curve Dental

- **URL:** https://www.curvedental.com/
- **Fecha de investigación:** 2026-11-16

## Problema que resuelve
Software dental cloud (navegador) con agenda, reserva online, perio, imágenes, pagos y facturación de seguros.

## Usuarios objetivo
Consultorios dentales de EEUU y Canadá.

## Features detectadas
- Reserva online, scheduling, recordatorios y comunicación con pacientes
- Charting y perio charting
- Imágenes (lista de compatibilidad)
- Curve Pay, facturación de pacientes, claims
- Funciona en Mac, PC y Chromebook sin servidor local

## Pricing
No publicado (requiere cotización; hay página de precios sin cifras).

## Posicionamiento
Cloud puro desde 2004 para consultorios.

## Diferenciadores
Cloud maduro; algunas funciones 'solo EEUU' declaradas.

Servicios 'solo EEUU' en algunas funciones; sin precios públicos. Contexto: referencia internacional.
